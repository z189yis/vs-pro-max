# 水晶防守模式（Defense Mode）设计文档

> 版本 v1.0 · 2026-07-31
> 双模式：现有「生存模式」保留，新增「水晶防守模式」。
> 设计目标：完整可玩的第一版 + 明确留出后续扩展点（用 `[扩展]` 标注）。

---

## 1. 玩法总览

经典 War3 防守图体验：**选英雄 → 守水晶 → 波次进攻 → 金币/木材双货币 → 木材 Roll 构筑 → 每 10 级突破 → 20 波通关**。

- **胜利**：坚守 20 波（第 20 波为最终 Boss 波），击败最终 Boss 即通关。
- **失败**：水晶血量归零。
- **角色死亡**：不影响胜负，3 秒后在水晶旁复活（死亡代价 = 掉金币 + 短暂的防守空档）。
- **节奏**：刷怪 30 秒 + 发育窗口 15 秒交替；第 5/10/15/20 波为 Boss 波（小怪 + Boss 同刷）。

## 2. 模式分发与架构（M1 前提）

### 2.1 模式注册表

```js
// src/modes.js（新增）
export const MODES = {
  survival: {
    id: 'survival', name: '生存模式', desc: '无限生存 · 升级三选一',
    start() { ... },      // 入口：初始化并启动
    dispose() { ... }     // 退出：释放（选模式页返回）
  },
  defense: {
    id: 'defense', name: '水晶防守', desc: '守水晶 20 波 · 木材 Roll 构筑',
    start() { ... },
    dispose() { ... }
  }
};
```

- `main.js` 只负责：挂载 `modeSelect` 界面、把点击分发到 `MODES[id].start()`。
- 每个模式持有自己的入口模块，**不直接 import 对方**。
- `[扩展]` 新模式 = 新增一个 entry 模块 + 注册表一行，无需改动其他模式。

### 2.2 模式内部架构（defense）

```
src/defense/
  entry.js          # 模式入口：DOM 装配、启动入口
  state.js          # 模式数据：英雄、水晶、波次、金币/木材、roll 状态
  wave.js           # 波次调度器
  crystal.js        # 水晶实体（血量/升级/修理/防护罩）
  economy.js        # 金币/木材掉落与 UI
  roll.js           # Roll 面板（3选1/锁定/重抽）
  breakthrough.js   # 突破/法宝系统
  update.js         # 主更新（敌人 AI 目标水晶、波次驱动、玩家重生）
  render.js         # 渲染（水晶、波次条、商店按钮）
```

- 复用现有：`src/utils.js`（对象池/SpatialGrid/相机）、`src/entities.js`（敌人池/元素反应）、`src/weapons.js`（武器发射）、`src/audio.js`。
- **不复用**：`src/game.js` 的生存模式主循环（节奏完全不同）。

### 2.3 存档与局外成长（预留）

- `localStorage` 键：`vspro_meta_2026`。记录：通关次数、击杀数、解锁的英雄、难度星级、累计木材。
- `[扩展]` 局外天赋树 / 难度 N1-N9：读同一个 meta 对象，不破坏现有存档结构。

## 3. 英雄系统（M1：选择；M4：突破）

### 3.1 英雄定义（开局 3 选 1）

```js
// src/defense/heroes.js（新增）
export const HEROES = [
  {
    id: 'knight', name: '铁壁骑士', icon: '🛡️',
    desc: '近战定位 · 生命+60 · 受到伤害-15%',
    statMods: { maxHp: 60, dmgTakenMult: 0.85 },   // 应用到 player
    passive: 'thorns',                              // 被动标识
  },
  { id: 'assassin', name: '疾风刺客', icon: '🗡️',
    desc: '攻速定位 · 普攻伤害+50% · 移速+15%',
    statMods: { attackDmgMult: 1.5, speedMult: 1.15 },
    passive: 'crit', },
  { id: 'mage', name: '奥术贤者', icon: '🔮',
    desc: '法术定位 · 武器伤害+25% · 技能冷却-15%',
    statMods: { dmgMult: 1.25, cdMult: 0.85 },
    passive: 'manaCascade', },
];
```

- `statMods`：键与 player 字段一一对应，`applyHero()` 里循环 `Object.assign`。**新增英雄 = 新增一条定义**，无需改系统代码。
- 初始武器：骑士 = 大蒜，刺客 = 飞刀，贤者 = 魔法飞弹（贴合定位）。
- `[扩展]` 英雄数量扩充（弓手/召唤师/牧师……）；每个英雄可追加 `skills`（专属技能池）。

### 3.2 被动技能（英雄被动，随突破强化）

| 被动 | 效果 |
|---|---|
| thorns 荆棘 | 被击中时对攻击者反弹伤害 |
| crit 暴击 | 普攻 20% 概率 2 倍伤害 |
| manaCascade 奥能涌动 | 击杀有 10% 概率重置随机武器冷却 |

- `[扩展]` 被动做成 5 级成长：`player.heroPassiveLv`，每级提升数值。

## 4. 水晶系统（M1：实体；M2：修理/升级）

### 4.1 水晶实体

```js
// src/defense/crystal.js
export const crystal = {
  x: 0, y: 0, hp: 500, maxHp: 500,
  level: 1, shield: 0, regen: 0,
};
```

- 位置：固定在出生点（`(0, 0)`，与生存模式玩家初始位一致），渲染为菱形水晶。
- 敌人 AI（M1）：所有敌人目标改为**水晶**，靠近后攻击（伤害 = 敌人 `dmg`）。
- 玩家死亡：3 秒倒计时后在水晶旁复活，复活动画期间无敌 1 秒。
- `[扩展]` 水晶掉落物：被杀时爆出大量金币 + 木材，鼓励防守。

### 4.2 修理与升级（M2）

| 操作 | 消耗 | 效果 |
|---|---|---|
| 修理 | 金币 50 | 恢复 25% 最大生命 |
| 升级 Lv2 | 木材 10 | 血量上限 +150，解锁"每秒回血 +1" |
| 升级 Lv3 | 木材 20 | 血量上限 +200，解锁"防护罩：每 45 秒抵挡一次任意伤害" |
| 升级 Lv4 | 木材 35 | 血量上限 +300，解锁"伤害反射 15%" |

- 升级为一次性（每级只升一次），修理可重复。
- 操作方式：水晶旁显示交互按钮（触碰/点击），HUD 显示水晶血条 + 升级按钮。
- `[扩展]` 水晶终极形态 Lv5（木材 60）：水晶攻击光环 / 水晶炮台自动开火。

## 5. 波次系统（M1：调度；M2：Boss 波掉落）

### 5.1 调度器

```js
// src/defense/wave.js
const waveState = {
  number: 0,            // 当前波数 1-20
  phase: 'fight',       // fight | break
  fightTimer: 0, breakTimer: 0,
  bossWave: false,
};
```

- **fight**（30 秒）：按时间表刷怪。间隔 `max(0.8, 2.2 - wave*0.06)` 秒刷一小队，总怪数 = `4 + wave * 2`（上限 250，复用敌人池）。
- **break**（15 秒）：刷怪停止，剩余怪继续存在并进攻（不消失），玩家利用窗口发育。
- 第 5/10/15/20 波为 **Boss 波**：fight 中途刷 1 只 Boss + 小怪继续出；Boss 有 3~4 倍血量、2 个技能（见 §5.3）。
- 第 20 波胜利条件：Boss 死亡 = 通关 → 结算画面（统计/重开/回主菜单）。

### 5.2 敌人强度曲线（波次驱动，替代生存模式的时间驱动）

```
hp 倍率 = 1 + (wave - 1) * 0.18 + (wave >= 5 ? (wave-5)^1.6 * 0.03 : 0)
移速 = 基础 * (1 + wave * 0.01)
```

- 敌人元素/天气系统复用（`spawnEnemy` 已有逻辑），天气效果保留但频率降低（每 60-90s 切换，避免和波次节奏抢注意力）。
- `[扩展]` 精英词缀怪：第 8/13/18 波出 1~2 只带词缀（灼烧光环/分裂/快速）的精英。

### 5.3 Boss 技能（M2 起启用）

| 技能 | 行为 |
|---|---|
| 震地波 | 对水晶方向释放直线 AOE，减速命中敌人 |
| 召唤 | 召唤 4 只小怪（在 Boss 周围） |

- Boss 死亡掉落：大量金币（40）+ 木材（5）+ 概率稀有材料。
- `[扩展]` Boss 技能库扩充（弹幕/冲锋/分裂死亡），每个 Boss 随机抽 2 个。

## 6. 双货币经济（M2）

### 6.1 掉落规则

| 来源 | 金币 | 木材 |
|---|---|---|
| 普通小怪 | 1（20% 概率）| — |
| 精英怪 | 5 | 1（50%）|
| Boss | 40 | 5 |
| 玩家死亡 | 掉 10% 金币（下限 0）| — |

- 金币/木材在地图上为拾取物（复用 xpGem 池，`_isGold` / `_isWood` 标记），磁铁拾取逻辑复用。
- 金币数字漂浮在 HUD，木材显示为 🌲 图标。

### 6.2 花费

- 修理水晶 50 金币；水晶升级 = 木材。
- Roll 面板：基础 3 选 1 = 免费每次？否 —— **免费 roll 第一轮，重抽 2 木材/次**，锁定 1 木材（见 §7）。
- `[扩展]` 金币商店：药水、属性书、回城卷轴。

## 7. Roll 构筑系统（M3）

### 7.1 面板与操作

- 按 **R**（移动端：右下角按钮）打开 Roll 面板，游戏暂停（类似升级面板）。
- **3 张卡**：从技能池抽 3 个不同技能（优先从未拥有的抽，抽满后全池随机）。
- 操作：选择 1 张（免费获得）/ **重抽**（2 木材，替换全部 3 张）/ **锁定**（1 木材，锁定当前 3 张直到关闭面板，期间只能从中选 1 张）。
- 关闭面板（Esc / 再次按 R / 点空白）= 放弃本次机会。
- 冷却：每次打开面板需水晶波间（break）——**fight 期间不可打开**（波间限制强化"发育窗口"节奏）。

### 7.2 技能池（现有 13 武器 + 新增被动）

- **武器技能**：13 个现有武器全部入库（复用 `fireWeapon`）。
- **被动技能**（新）：

| id | 名称 | 效果 |
|---|---|---|
| lifesteal | 吸血 | 击杀回 1 HP |
| thorns | 荆棘 | 被击中时反弹伤害（与英雄被动叠加）|
| crit | 暴击 | 普攻 15% 概率 2 倍伤害 |
| multishot | 多重 | 普攻 +1 发射方向 |
| berserk | 狂暴 | 每击杀 10 只怪，5 秒内攻速 +50% |
| void | 虚空 | 受击时 10% 概率免疫该次伤害 |

- 与生存模式的区别：**防御模式没有"升级三选一"**——所有成长来自 Roll + 突破。
- 玩家可持有：武器 6 格（复用 `player.weapons`）+ 被动 6 格（新 `player.passives` 数组）。
- `[扩展]` 装备词条系统：3 件同名技能 → 合成升级（Lv1→Lv2→Lv3），后续迭代。

### 7.3 状态与数据

  open: false, cards: [], locked: false,
  rollCost: 2, lockCost: 1,

## 8. 突破 / 法宝系统（M4）

- 英雄每 10 级触发**突破**（10/20/30 级……），替代生存模式的升级面板。
- 突破面板：3 选 1 **法宝**：

| 法宝 | 效果 |
|---|---|
| 力量图腾 | +25 最大生命，+10% 全伤害 |
| 疾风之靴 | +10% 移速，+8% 攻速 |
| 贤者之石 | 武器冷却 -8%，普攻伤害 +15% |

- 每次突破随机 3 个，选过的可再出现（数值叠加）。
- `[扩展]` 法宝库扩充 + 专属法宝（按英雄）。

## 9. UI / 反馈

- **HUD 新增**：水晶血条（顶部中央，始终可见）、波次进度（`第 7/20 波` + 阶段条）、金币/木材计数。
- **Boss 警告**：Boss 波开始前 5 秒全屏红字"⚠ BOSS 波来袭 ⚠"。
- **通关/失败结算**：统计（波数/击杀/通关耗时/累计金币木材）+ 按钮（再来一局 / 回主菜单）。
- 所有面板复用现有 DOM overlay 模式（upgrade-overlay 的样式体系）。

## 10. 里程碑划分（对应开发顺序）

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M1 | 模式分发 + 选英雄 + 水晶实体 + 波次调度 + 敌人 AI 目标水晶 + 玩家重生 + 胜负判定 | 能选英雄开局、波次刷新、水晶掉血、死亡复活、水晶爆=失败 |
| M2 | 金币/木材掉落 + 水晶修理 + 水晶升级树 + Boss 波掉落 | 双货币可见可花、水晶可修可升级、Boss 波可打 |
| M3 | Roll 面板（3选1/锁定/重抽）+ 被动技能池 | 木材 roll 技能、被动生效、面板交互完整 |
| M4 | 突破/法宝系统 | 10 级突破三选一、法宝生效 |
| M5 | 打磨：公告、音效、HUD 完善、平衡数值、通关结算 | 可完整通关一局 |
